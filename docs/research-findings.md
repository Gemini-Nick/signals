## 1. 职业交易员日常工作流

### 研究发现

职业交易员的一天严格按照四个阶段运作，每个阶段有不同的思维模式和输出产物：

**盘前（6:00-9:15）— 制定作战计划**
- 审查隔夜市场（美股/欧洲/期货/外汇）
- 扫描新闻事件（财报、政策、地缘政治）
- 标记关键价位（支撑/阻力/枢轴点）
- 制定当日交易计划：方向偏好 + 具体入场/出场条件
- **关键原则**：不是猜方向，而是设定「如果…则…」的条件框架

**盘中（9:15-15:00）— 执行与应对**
- 严格按盘前计划执行
- 信号驱动：只在预设条件触发时行动
- 不做计划外的冲动交易
- 实时记录交易日志

**盘后（15:00-17:00）— 复盘与总结**
- 逐笔回顾当日交易
- 记录错误并分类
- 更新统计指标（胜率/盈亏比/最大回撤）
- 为次日准备初步观察

**周末 — 大局思考**
- 周线级别结构分析
- 下周事件日历审查
- 仓位再平衡
- 策略回顾与参数微调

### 对系统设计的启示

1. **四阶段循环是自然的工作流**，不是人为划分
2. 每个阶段的**输入/输出/思维模式完全不同**
3. 盘前的核心是「完全分类 + 分段函数」，不是单一预测
4. 盘中的核心是「应对」，不是「预测」
5. 盘后的核心是「归因」，不是「总结涨跌」

## 2. 量化基金环境分离思路

### 研究发现

**幻方量化（Nine Chapters）/ Two Sigma / Renaissance 的因子管线**

量化基金严格分离三个环境：

| 环境 | 数据 | 目的 | 隔离 |
|------|------|------|------|
| **研究环境（Research）** | 历史全量 | 因子挖掘、策略研发 | 不可执行交易 |
| **回测环境（Backtest）** | 历史 + 模拟撮合 | 策略验证、参数优化 | 严防未来信息 |
| **生产环境（Production）** | 实时行情 | 实盘执行 | 风控隔离 |

**幻方的核心理念**：
- 因子 alpha 是通过**大量统计检验**发现的，不是人为设定的
- 回测必须防止「过拟合」和「未来函数」
- 生产环境有独立的风控层，策略无法绕过

**对隆小侠的借鉴**：
- 仿真环境（sim）= 回测环境，必须严格隔离数据
- 盘中监控（intraday）= 生产环境，用实时数据
- 盘前/盘后/周末 = 研究环境的不同视角
- **环境之间不应该混用同一个代码路径**

### 关键设计原则

1. **数据隔离**：仿真用快照数据（SimDataSource），盘中用实时数据
2. **信号一致性**：同一个检测器（detectors.py）在所有环境中复用
3. **输出差异化**：不同环境的输出格式和关注点不同
4. **无未来信息**：仿真/回测中严禁使用未来数据

## 3. 缠论实战者工作流

### 研究发现

**缠论实战者的典型日常**（来自缠论108课及实战社区）：

**盘前 — 完全分类**
- 确定操作级别（如30分钟）
- 画出当前中枢位置（ZG/ZD）
- 枚举所有可能走势（上/中/下三种分类）
- 每种分类设定操作预案
- 计算关键价位（中枢边界、笔的目标位）

**盘中 — 当下判断**
- 「走势终完美」：任何走势终将完成
- 跟踪市场选择了哪个分类
- 当分类确认时执行预案
- 多级别联立：大级别定方向，小级别定入场

**盘后 — 复盘结构**
- 画图（笔/线段/中枢）
- 验证盘前分类是否覆盖了实际走势
- 如果走势超出分类 → 分析哪里判断有误
- 更新中枢位置为次日准备

**缠论第68课核心思想**：
> 「用完全分类的方式对待市场，每种分类配一个操作，这就是分段函数。市场走到哪个分类，就执行哪个操作，不需要预测市场一定走哪个方向。」

### 对系统设计的启示

1. 盘前计划的输出必须是**分段函数**，不是单一方向
2. 每个分类需要明确的**触发条件**和**操作预案**
3. 盘中是「选择执行哪个分段」，不是「重新分析」
4. 盘后是「验证分类覆盖度」，不是「事后诸葛亮」

## 4. 波浪理论与缠论对比

### 波浪理论核心

**Elliott Wave（艾略特波浪理论）基本结构**：
- 推动浪：5浪结构（1-2-3-4-5）
- 调整浪：3浪结构（A-B-C）
- 浪中有浪：分形结构（fractal）

**三大铁律**：
1. 浪2不能跌破浪1起点
2. 浪3不能是最短的推动浪
3. 浪4不能与浪1重叠（非斜纹浪）

**斐波那契关系**：
- 浪2通常回撤浪1的 38.2%-61.8%
- 浪3通常是浪1的 1.618 倍
- 浪5通常等于浪1 或是浪1的 0.618 倍
- 浪A-B-C 的 C 浪通常等于 A 浪

### 缠论对波浪理论的批评

**「千人千浪」问题**：
- 波浪理论的最大弱点是**主观性**：同一段走势，不同人数出不同的浪形
- 没有严格的数学定义，浪的划分依赖经验
- 「失败浪」「延伸浪」等概念使得理论几乎不可证伪

**缠论的解决方案**：
- 用**分型-笔-线段**的严格数学定义替代波浪计数
- 中枢的定义是精确的（三笔重叠区间），不依赖主观判断
- 完全分类取代浪形预测：不数浪，而是枚举所有可能

### 可借鉴之处

尽管缠论批评波浪理论，但以下元素值得融合：

1. **斐波那契比例**：笔的延伸目标位可用 0.618/1.618 计算
2. **调整浪形态**：A-B-C 调整与缠论中枢回调结构有对应关系
3. **浪的时间对称性**：推动浪与调整浪的时间比例有参考价值
4. **分形思维**：波浪理论的自相似性与缠论多级别递归一致

### 系统设计融合

- **目标位计算**：中枢 ZG/ZD 为主 + 斐波那契 0.618/1.618 为辅
- **不采用浪形计数**：完全用缠论笔/线段/中枢体系
- **保留比例关系**：笔的等长投射、0.618回撤作为参考

## 5. 缠论均线系统 — 三种吻

### 研究发现

**缠论中均线的三种关系（三种吻）**：

| 类型 | 定义 | 含义 | 级别提示 |
|------|------|------|---------|
| **飞吻** | 短期均线靠近长期均线但不接触即弹开 | 趋势极强，回调极浅 | 次级别回调不充分 |
| **唇吻** | 短期均线接触长期均线后弹开 | 正常回调，趋势延续 | 次级别回调充分 |
| **湿吻** | 短期均线穿越长期均线后纠缠 | 可能反转区域 | 次级别可能形成中枢 |

**缠论对均线的独特理解**：
- 均线不是简单的多空分界线
- 均线的「吻」反映的是**趋势的力度和耐力**
- 飞吻连续出现 = 趋势加速（但物极必反）
- 湿吻出现 = 趋势力度衰减，可能变盘

**均线系统与中枢的关系**：
- 中枢上方运行 + 飞吻 = 强势趋势延续
- 中枢内运行 + 湿吻 = 震荡区间
- 跌破中枢 + 均线死叉 = 趋势反转确认

### 对系统的应用

1. **MA均线关键位**（已实现在 `signals/core/ma_levels.py`）需要增加「吻」的识别
2. 均线吻的类型可以作为**信号确认的辅助指标**
3. 飞吻→唇吻→湿吻 的演变是**趋势力度衰减的预警**
4. 在盘前计划中，均线的吻类型可以辅助判断分类概率

## 6. MACD 动力学 — 面积比较法

### 研究发现

**缠论中 MACD 的核心用法 — 面积比较法**：

MACD 不是简单看金叉死叉，而是用**面积比较**来判断趋势力度：

**A-B-C 三段框架**：
```
价格:  ↗ A段（第一段上涨）→ ↘ B段（回调）→ ↗ C段（第二段上涨）
MACD:  面积A（红柱区域）   →  面积B（绿柱）  →  面积C（红柱区域）

判断: 若 面积C < 面积A → 顶背驰 → 卖出信号
      若 面积C > 面积A → 力度增强 → 继续持有
```

**黄白线回零轴**：
- 黄白线（DIF/DEA）回到零轴附近 = 中枢震荡
- 黄白线远离零轴 = 趋势延续
- **双回试**：黄白线两次回到零轴附近 = 两个中枢形成，可能趋势反转

**MACD 面积与中枢的对应**：
- 每一段趋势内的 MACD 面积代表该段趋势的「力度」
- 相邻两段同方向趋势的面积对比 = 背驰判断
- 背驰 + 中枢位置 = 买卖点定位

**具体公式**：
```
背驰力度 = MACD面积(当前段) / MACD面积(前一同向段)
  > 1.0: 力度增强（非背驰）
  = 0.5~1.0: 轻微背驰
  < 0.5: 明显背驰（高概率反转）
```

### 对系统的应用

1. 当前 `detectors.py` 使用 `bi.power_price` / `bi.power_volume` 检测背驰
2. 可以增加 **MACD 面积量化指标**，作为背驰的第三重确认
3. 黄白线回零轴次数可以辅助判断**中枢级别**
4. 面积递减趋势可以作为**盘前计划分类概率**的参考

## 7. 道氏理论与缠论对比

### 道氏理论核心

**六大原则**：
1. 市场反映一切（与缠论「市场永远是对的」一致）
2. 三种趋势（主要/次要/短暂 ≈ 缠论的多级别）
3. 主要趋势三阶段（积累/参与/派发 ≈ 缠论的三类买卖点）
4. 指数必须相互确认（≈ 缠论的多指数共振）
5. 成交量必须确认趋势（≈ 缠论的量价配合）
6. 趋势延续直到明确反转（≈ 缠论「走势终完美」）

### 缠论对道氏理论的继承与超越

| 概念 | 道氏理论 | 缠论 | 改进 |
|------|---------|------|------|
| 趋势定义 | 更高的高点和更高的低点 | 线段/笔的方向 | 数学精确 |
| 趋势级别 | 主要/次要/短暂（模糊） | 1F/5F/30F/日/周（精确递归） | 可递归定义 |
| 反转信号 | 高点/低点被突破 | 中枢 + 背驰 + 买卖点 | 多重确认 |
| 入场时机 | 「确认后买入」（滞后） | 区间套精确定位 | 精度更高 |

### 可借鉴之处

1. **指数相互确认**原则已体现在 Layer 1（11指数多市场）
2. **成交量确认**可以加强（当前系统对量能分析较弱）
3. **趋势延续假设**：在没有背驰信号前，默认持有 → 减少过度交易

## 8. 东方哲学基础

### 研究发现

缠论创始人在108课中频繁引用三大经典，这些不是装饰而是分析哲学的根基：

**《道德经》— 「反者道之动」**
- 任何趋势走到极端必然反转
- 「弱者道之用」：市场在最弱的时候蕴含着最强的力量（底背驰）
- 对系统的启示：**逆向情绪标签**（已实现在 market_context.py）的理论基础

**《金刚经》— 「应无所住而生其心」**
- 不执着于任何一种走势预判
- 完全分类就是「不住」：不住多，不住空，住在「所有可能」之中
- 对系统的启示：盘前计划必须是**分段函数**，不能是单方向预测

**《论语》— 「知之为知之，不知为不知」**
- 承认市场的不可预测性
- 只在确定性高的信号出现时行动
- 对系统的启示：信号必须有**置信度**（confidence），低置信度信号只观察不操作

### 核心哲学映射

| 哲学原则 | 缠论体现 | 系统实现 |
|---------|---------|---------|
| 反者道之动 | 背驰必反转 | 背驰检测 + 逆向情绪 |
| 应无所住 | 完全分类 | 分段函数式盘前计划 |
| 知之为知之 | 确定性优先 | 信号置信度评分 |
| 道法自然 | 走势终完美 | 不预测，等走势完成 |
| 物极必反 | 三买三卖 | 中枢突破后的衰竭检测 |

## 9. 盘前计划 — 目标位计算方法

### 研究发现

**四种目标位计算方法**（按精度排序）：

#### 方法一：中枢边界法（最基础）

```
中枢 = 三笔重叠区间
ZG = 中枢上沿 = min(第2笔高点, 第3笔高点)
ZD = 中枢下沿 = max(第1笔低点, 第2笔低点)

第一级支撑 = ZD
第一级阻力 = ZG
```

- 最简单，所有缠论使用者都用
- 精度较低，只能给出大致区间

#### 方法二：区间套精度法（核心方法）

```
大级别背驰段定位 → 次级别精确定位 → 更小级别精确区间

例：日线出现顶背驰
→ 在30分钟找到对应的趋势段
→ 在5分钟找到最后一个中枢的ZG
→ 5分钟ZG就是精确卖出区域
```

- 缠论最核心的精确定位方法
- 需要多级别联动（当前系统已支持）
- 精度可以到具体价格±1%

#### 方法三：新中枢形成目标法

```
趋势中新中枢的形成位置可以预估：
- 上涨趋势中，新中枢通常在前一中枢ZG上方
- 新中枢的ZD ≈ 前一中枢的ZG（理想情况）
- 新中枢的高度 ≈ 前一中枢高度的 0.618-1.0 倍
```

- 适用于趋势延续的目标位估算
- 需要历史中枢高度的统计数据

#### 方法四：斐波那契延伸法（辅助）

```
笔的等长投射：
目标 = 起点 + (前一同向笔的长度)

0.618/1.618延伸：
目标 = 起点 + 前一同向笔长度 × 0.618
目标 = 起点 + 前一同向笔长度 × 1.618
```

- 来自波浪理论，作为辅助参考
- 不单独使用，与中枢法/区间套法交叉验证
- 多种方法在同一区域汇聚 = 强支撑/阻力

### 系统实现建议

```python
class TargetCalculator:
    def zhongshu_boundaries(self, czsc) -> Dict:
        """方法一：中枢ZG/ZD"""

    def interval_nesting(self, czsc_multi_freq) -> Dict:
        """方法二：区间套精确定位"""

    def new_zhongshu_target(self, czsc) -> Dict:
        """方法三：新中枢形成目标"""

    def fibonacci_extension(self, czsc) -> Dict:
        """方法四：斐波那契延伸"""

    def combined_targets(self) -> List[PriceLevel]:
        """综合所有方法，标记汇聚区域"""
```

## 10. 盘后复盘 — 错误分类框架

### 研究发现

**职业交易员的三类错误分类（A/B/C分类法）**：

#### Type A — 系统方差（System Variance）

- 定义：严格执行策略，但仍然亏损
- 原因：市场随机性，任何策略都有一定的亏损比例
- 处理：**接受，不修改策略**
- 占比目标：≥60%（大部分损失应该是这类）
- 示例：30M二买信号出现，买入后结构破坏，止损出场

#### Type B — 执行失误（Execution Error）

- 定义：信号正确，但执行有偏差
- 常见类型：
  - 移除止损（最危险）
  - 仓位过重
  - 提前入场（信号未确认就买）
  - 延迟出场（犹豫不决）
- 处理：**记录并改善执行纪律**
- 占比目标：≤30%
- 示例：设定止损12.10，但跌到12.10时犹豫不出，结果跌到11.80

#### Type C — 情绪交易（Emotional Trade）

- 定义：完全不在计划内的交易
- 常见类型：
  - 看到某股大涨追入（FOMO）
  - 亏损后报复性加仓
  - 听消息买入
- 处理：**严格禁止，发现一次记录一次**
- 占比目标：≤10%
- 示例：午盘看到某股拉涨停，追入，无任何信号支撑

### 遗漏分析（Omission Analysis）

除了错误交易，还要分析**该做但没做的操作**：

```
遗漏 = 系统发出信号 + 满足入场条件 + 未执行

遗漏成本 = 如果执行了，收益是多少？
遗漏率 = 遗漏次数 / 总信号数

目标遗漏率: < 20%
```

遗漏的原因通常是：
- 当时在做其他事情（注意力分散）
- 信号出现时犹豫不决
- 刚亏损后害怕下一次操作

### 执行评分（1-5分制）

| 分数 | 含义 |
|------|------|
| 5 | 完美执行：信号-入场-仓位-止盈/止损 全部正确 |
| 4 | 基本正确：小偏差（入场略早/晚1-2根K线） |
| 3 | 有瑕疵：仓位不当或止损设置不合理 |
| 2 | 明显失误：执行与计划严重偏离 |
| 1 | 严重错误：完全脱离系统的操作 |

#### 事件预案模板

```
事件: FOMC利率决议
日期: 2026-03-12
当前市场预期: 维持利率不变 (85% 概率)

情景A (鸽派, 概率30%):
  表述: 暗示6月降息
  影响: 纳斯达克+2%, 成长股利好
  操作: 可加仓科技/成长
  缠论叠加: 若沪深300在日线中枢上沿 → 可能触发三买

情景B (中性, 概率55%):
  表述: 措辞不变，数据依赖
  影响: 市场小幅波动
  操作: 不调整

情景C (鹰派, 概率15%):
  表述: 通胀顽固，推迟降息
  影响: 纳斯达克-3%, 风险资产承压
  操作: FOMC前减仓至5成
  缠论叠加: 若沪深300在日线中枢内 → 可能跌破中枢下沿
```

### 缠论结构 x 事件叠加的核心逻辑

**事件不创造趋势，但可以成为结构突破的催化剂**：

```
场景1: 市场在中枢震荡 + 重大事件来临
  → 事件可能是突破中枢的催化剂
  → 需要双向准备

场景2: 市场在趋势延续中 + 无重大事件
  → 趋势大概率延续
  → 关注技术面背驰信号

场景3: 市场在背驰末端 + 重大事件来临
  → 事件可能加速反转
  → 需要提前布局反向
```

### 数据源建议

- **AKShare**: `stock_em_macro_event` (东财经济日历)
- **Tushare**: `econ_cal` (经济事件日历)
- **人工维护**: 重大政治事件（两会、政治局会议等）需要手动维护
- **新闻 API**: 可选接入新闻聚合 API 扫描关键词
