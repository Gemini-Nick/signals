## 三、优化方案

### P0-1: 指数均线关键位（价格地图）

#### 问题
道长几乎每个操作都锚定在均线上："5周线"、"10月线"、"10日线20日线"。系统只输出中枢区间和当前价，**不告诉你关键支撑/阻力在哪**。

#### 设计关键：只做日线及以上，不做分钟线

均线在不同时间周期（15min/30min/日线/周线/月线）值完全不同。如果每个级别都输出 MA，和现有的多级别买卖点混在一起，用户会信息过载、无法形成明确操作意见。

**解决方案：均线只计算日线级别以上**（日/周/月），小级别（15min/30min）继续纯缠论。

理由：
- 道长使用的均线全部是日线以上级别（5周线、10月线、10日线、20日线）
- 小级别均线噪音大、变化快，缠论的笔/中枢结构在小级别已经足够
- 均线的价值是给出"稳定的、市场共识的价位锚点"，这只有大级别才有意义

#### 输出形式：合并为"关键价位"板块

不是在每行指数后面堆 MA，而是提炼出 2-3 个最关键的支撑/阻力位，形成"价格地图"：

```
上证50   ↑↓↑  二买(日+15)  [3077~3080]  3047
  关键位: ▼5周线 2970(-2.5%)  ▼10月线 2870(-5.8%)  ▲前高 3177(+4.3%)
```

这样用户一眼看到：缠论说"二买"（方向），价格地图说"下方5周线2970是最近支撑"（位置）。方向+位置=可操作。

#### 计算逻辑

均线全部从日线 bars 派生：
- **日线 MA**: MA5, MA10, MA20, MA60（从 `bars_raw` 的 close 序列直接计算）
- **周线 MA**: 日线 resample 为周线后计算 MA5(5周线), MA10, MA20（复用已有的 `resample("W-FRI")` 模式）
- **月线 MA**: 日线 resample 为月线后计算 MA10(10月线)

输出 `MAContext`：
```python
@dataclass
class MALevel:
    name: str           # "5周线", "10月线", "20日线"
    value: float        # 均线值
    distance_pct: float # 当前价距该均线 %
    position: str       # "上方" / "下方" / "贴合"(< 1%)

@dataclass
class MAContext:
    symbol: str
    latest_price: float
    levels: List[MALevel]            # 全部均线
    support_levels: List[MALevel]    # 当前价下方（按距离排序）
    resistance_levels: List[MALevel] # 当前价上方
    key_levels: List[MALevel]        # 提炼出最关键的2-3个（最近支撑+最近阻力+大级别锚点）
```

`key_levels` 的提炼规则：
1. 最近的下方均线支撑（通常是 20日线 或 5周线）
2. 最近的上方均线阻力（通常是前高或上方均线）
3. 大级别锚点（10月线，作为长期参考）

#### 数据需求
10月线需 ~200 交易日数据。当前 `INDEX_LOOKBACK_DAYS=180`(~120交易日) 不够。新增 `INDEX_MA_LOOKBACK_DAYS = 300`。

#### 改动范围
- 新增 `signals/core/ma_levels.py`
- 修改 `signals/layers/index_report.py` — IndexReport 增加 `ma_context` 字段
- 修改 `signals/layers/index_analyzer.py` — `report()` 中调用 MA 计算
- 修改 `signals/layers/market_context.py` — `_index_lines()` 增加关键价位行
- 修改 `config.py` — 新增 `INDEX_MA_LOOKBACK_DAYS`

### P0-2: 板块超跌检测

#### 问题
道长说"医药超跌"、"恒生科技超跌"作为弹性仓来源。系统只有全市场情绪，没有单板块超跌度量。双榜只看"谁强"，不看"谁跌过头"。

#### 为什么需要
追强（涨幅榜）和抄底（超跌）是两种互补逻辑。道长策略：主力仓追强（银行+顺周期），弹性仓抄底（超跌板块）。

#### 方案
在 `industry.py` 的 `IndustryRanking` 中增加超跌字段和计算逻辑。

超跌评分（满分 100）:

| 维度 | 权重 | 逻辑 |
|------|------|------|
| 距 20 日高点回撤 | 40 分 | >15% 满分，5~15% 线性 |
| 均线偏离度 | 30 分 | 低于 20 日均线 >10% 满分 |
| 连续下跌天数 | 15 分 | 5 天满分，3 天 10 分 |
| RSI 超卖 | 15 分 | RSI14 <30 满分，30~40 线性 |

数据来源：已有的东财板块 K 线接口（仅需近 30 日数据）。

#### 输出效果（概念标签以括号标注）
```
📊 涨幅榜: 有色金属[周期🔄](有色、稀土) +3.2%  化工[周期🔄](化工) +2.8%
🏆 综合榜: 有色金属(82分)  半导体[进攻⚔](芯片、AI) 75分
⬇️ 超跌关注: 医药[中性](创新药) 超跌78, 距高点-18%
```

> 注：概念标签（括号内）从已有的 `concept_tags` 字段提取，当前在输出中是单独一行 `概念: xxx`，改为紧跟行业名后面。

#### 改动范围
- 修改 `signals/layers/industry.py` — IndustryRanking 增加超跌字段 + 计算函数
- 修改 `run.py` — 行业输出格式调整（概念标签括号化）

### P0-3: 均线+缠论信号交叉确认

#### 问题
"化工暴跌，在10日线20日线5周线附近去捕"——缠论说方向（二买=结构向上），均线说位置（5周线=支撑位）。两者同时满足时信号最强。

当前评分系统不考虑"信号发生时价格在什么位置"。5周线上方10%的二买和刚好回踩5周线的二买，评分一样。

#### 方案
修改 `scorer.py` 的 `score_signals()`，增加可选 `ma_context` 参数：
- 缠论买信号 + 均线支撑位附近(< 2%): **+15 分**
- 缠论买信号 + 均线多头排列: **+10 分**
- 缠论买信号 + 均线空头排列: **-5 分**

#### 改动范围
- 修改 `signals/core/scorer.py`
- 调用方（`screener.py`/`review_screener.py`）传入 ma_context

### P1-1: 轮动线分类（科技/顺周期/消费）

#### 问题：为什么现有分类不够

当前 `SECTOR_TYPE_MAP` 把行业分为**防守/进攻/周期/中性**，这是**风险维度**分类（高beta vs 低beta）。

但道长的"三条线"是**轮动维度**分类（什么顺序轮动热炒）：
- **科技线**: 半导体、AI、软件、互联网——技术创新驱动
- **顺周期线**: 化工、有色、银行、航运、大船——经济复苏驱动
- **消费线**: 白酒、医药、食品、家电、旅游——消费复苏驱动

两个维度**不对等**，存在交叉：

| 行业 | 风险维度(现有) | 轮动维度(缺失) |
|------|---------------|---------------|
| 银行 | 防守 | **顺周期**（受益于利率和经济周期） |
| 白酒 | 防守 | **消费**（消费复苏驱动） |
| 军工 | 进攻 | **主题**（政策驱动，不在三线轮动中） |
| 半导体 | 进攻 | **科技**（技术创新驱动） |
| 有色金属 | 周期 | **顺周期**（经济周期驱动） |
| 医药 | 中性 | **消费**（消费属性为主） |
| 光伏 | 进攻 | **新能源**（介于科技和顺周期之间） |

#### 方案：新增轮动线分类维度

在 `config.py` 新增 `ROTATION_LINE_MAP`（和现有 `SECTOR_TYPE_MAP` 并存，不替代）：

### P1-2: 经典形态识别（扩展版）

#### 问题
道长提到双头。实际上缠论笔结构可以识别更多经典形态。

#### 形态清单（按 A 股实战重要性排序）

| 优先级 | 形态 | 笔数 | 信号 | 缠论映射 | 检测逻辑 |
|--------|------|------|------|---------|---------|
| 1 | **双头(M头)/双底(W底)** | 5+ | 空/多 | 背驰卖/二买 | 两个向上笔高点近似(<1%)，中间回调 |
| 2 | **头肩顶/头肩底** | 7+ | 强空/强多 | 背驰+二卖/一买+二买 | 左肩-头-右肩结构，右肩力度衰减 |
| 3 | **上升三角/下降三角** | 7+ | 多/空 | 三买/三卖 | 单边平台+另一边收敛 |
| 4 | **旗形(牛旗/熊旗)** | 5+ | 顺势延续 | 三买(回调不破中枢) | 旗杆力度>>旗面力度，缩量回调<38.2% |
| 5 | **箱体突破** | 7+ | 多/空 | 三买/三卖 | 高低点在固定范围内反复震荡 |
| 6 | **平台突破** | 9+ | 多 | 趋势买 | 前期涨20%+后横盘缩量+放量突破 |
| 7 | **下降楔形** | 5+ | 多 | 背驰买共振 | 高低点都递降但跌幅收窄 |
| 8 | **对称三角** | 5+ | 中性 | 中枢收缩 | 高点递降+低点递升 |
| 9 | **圆弧底** | 9+ | 多 | 一买区域 | 低点序列呈U形（二次拟合 a>0） |
| 10 | **扩张形态** | 5+ | 警示 | 分歧加大 | 高点递升+低点递降（喇叭口） |

#### 检测方法举例

**头肩顶**（7 笔）:
```
bi1↑ bi2↓ bi3↑ bi4↓ bi5↑ bi6↓
左肩  颈线  头部  颈线  右肩  跌破

条件：
  bi3.high > bi1.high          # 头比左肩高
  bi5.high < bi3.high          # 右肩低于头
  bi5.high ≈ bi1.high (±5%)   # 右肩≈左肩
  bi2.low ≈ bi4.low (±3%)     # 两颈线近似
  bi6.low < min(bi2.low, bi4.low)  # 跌破颈线确认

量能增强：bi5.power_volume < bi3.power_volume（右肩缩量→背驰）
```

**旗形**（旗杆 + 旗面）:
```
旗杆：1根大阳笔，power_price > 均值×1.5
旗面：随后3-7笔，power_price < 旗杆×0.4（缩量）
      回调深度 < 旗杆高度×38.2%
突破：出现一笔高于旗杆高点
```

**上升三角**:
```
高点序列平台化：max(|bi1.high - bi3.high|, ...) < 高度×2%
低点序列递升：bi2.low < bi4.low < bi6.low
突破确认：一笔 high 超过平台高度
```

#### 权重设计（辅助参考，不替代缠论）

```python

    "形态:上升三角": 10,  "形态:下降三角": -10,
    "形态:牛旗":    8,   "形态:熊旗":    -8,
    "形态:箱体突破": 10,  "形态:箱体跌破": -10,

    "形态:下降楔形": 8,
    "形态:圆弧底":  8,

# 对比缠论信号：二买 55分, 三买 50分 → 形态 8~15分 ≈ 缠论的 1/4~1/3
```

#### 与缠论的互补关系

| 经典形态 | 缠论映射 | 叠加价值 |
|---------|---------|---------|
| 头肩底(头部) | 一买(背驰买) | 互相确认底部反转 |
| 头肩底(右肩) | 二买 | 右肩=二买位置 |
| 上升三角突破 | 三买 | 突破=中枢上沿突破 |
| 旗形整理结束 | 三买(回调不破ZG) | 旗面=轻度回调 |
| 箱体 | 中枢 | 箱顶=ZG，箱底=ZD |

#### 分阶段实现建议
- Phase 1: 双头/双底 + 头肩顶/底 + 三角形（最基础最常用）
- Phase 2: 旗形 + 箱体突破 + 平台突破（强势股形态）
- Phase 3: 楔形 + 圆弧底 + 扩张形态（补充）

- 修改 `signals/core/detectors.py` — 新增 `_detect_patterns()` 函数
- 修改 `signals/core/scorer.py` — 新增 `PATTERN_WEIGHTS`

### P1-3: 底仓/弹性仓位分层

#### 问题
道长反复强调的核心策略："底仓要拿住，弹性筹码按回合制来搞"。系统只有单一 `position_pct`。

#### 方案
修改 `signals/core/risk.py` 新增：

```python
@dataclass
class LayeredPosition:
    base_pct: float          # 底仓比例（大级别信号→长持）
    flex_pct: float          # 弹性仓位（小级别+均线→波段）
    flex_buy_ref: str        # 弹性买入参考："5周线 2970"
    flex_sell_ref: str       # 弹性卖出参考："前高 3177"
    rationale: str
```

分层逻辑：
- **底仓**: 日线/周线级别买信号 → 长持，不因短期波动出局
- **弹性仓**: 15M/30M 信号 + 均线支撑/阻力 → 回合制高抛低吸

#### 改动范围
- 修改 `signals/core/risk.py`
- 修改 `signals/layers/market_context.py`（输出分层建议）

## 四、依赖关系

```
P0-1 均线关键位 ───┬──→ P0-3 均线交叉确认
                   ├──→ P1-3 仓位分层（弹性仓高抛低吸区间来自均线）
                   └──→ P2-2 配置比例

P0-2 超跌检测 ────→ P2-1 逆向标签

P1-1 轮动线分类 ──→ P2-2 配置比例

P1-2 形态识别 ────→ 完全独立
```

## 五、实施顺序

```
Phase 1 (P0):  均线关键位 → 超跌检测 → 均线交叉确认
Phase 2 (P1):  轮动线分类 → 形态识别(Phase1) → 仓位分层
Phase 3 (P2):  逆向标签 → 配置比例 → 形态识别(Phase2+3)
```
